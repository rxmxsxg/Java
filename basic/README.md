# Java Versions Timeline

## Overview
Java has evolved significantly since its initial release in 1996. Below is a timeline of major Java versions and their notable features.

| Version | Release Year | Key Features |
|----------|-------------|--------------|
| Java 1.0 | 1996 | First public release |
| Java 1.1 | 1997 | Inner classes, JDBC, JavaBeans |
| Java 1.2 (Java 2) | 1998 | Collections Framework, Swing |
| Java 1.3 | 2000 | HotSpot JVM improvements |
| Java 1.4 | 2002 | Assertions, NIO, Regular Expressions |
| Java 5 (1.5) | 2004 | Generics, Annotations, Enhanced For Loop, Autoboxing |
| Java 6 | 2006 | Performance enhancements, Compiler API |
| Java 7 | 2011 | Try-with-resources, Diamond Operator, NIO.2 |
| Java 8 | 2014 | Lambda Expressions, Streams API, Date & Time API |
| Java 9 | 2017 | Module System (Project Jigsaw), JShell |
| Java 10 | 2018 | Local Variable Type Inference (`var`) |
| Java 11 (LTS) | 2018 | HTTP Client API, Long-Term Support Release |
| Java 12 | 2019 | Switch Expressions (Preview) |
| Java 13 | 2019 | Text Blocks (Preview) |
| Java 14 | 2020 | Records (Preview), Pattern Matching (Preview) |
| Java 15 | 2020 | Text Blocks (Standard), Hidden Classes |
| Java 16 | 2021 | Records (Standard), Pattern Matching Improvements |
| Java 17 (LTS) | 2021 | Sealed Classes, Long-Term Support Release |
| Java 18 | 2022 | Simple Web Server, UTF-8 by Default |
| Java 19 | 2022 | Virtual Threads (Preview) |
| Java 20 | 2023 | Continued Virtual Thread Enhancements |
| Java 21 (LTS) | 2023 | Virtual Threads, Record Patterns, Pattern Matching for Switch |
| Java 22 | 2024 | Foreign Function & Memory API Improvements |
| Java 23 | 2024 | Preview and Performance Enhancements |
| Java 24 | 2025 | Feature Release |
| Java 25 (LTS) | 2025 | Long-Term Support Release |

## Long-Term Support (LTS) Releases

The following Java versions are designated as LTS releases:

- Java 8 (2014)
- Java 11 (2018)
- Java 17 (2021)
- Java 21 (2023)
- Java 25 (2025)

## Recommended Versions

### For Legacy Applications
- Java 8

### For Enterprise Applications
- Java 17 (LTS)
- Java 21 (LTS)

### For New Development
- Java 21 (LTS)
- Java 25 (LTS)

## Check Installed Java Version

```bash
java -version
```

Check Java Compiler Version:

```bash
javac -version
```
